BGM（魔王魂 https://maou.audio/）
==================================

すべて MIDI で鳴らしている（wizrpg/midi.js の簡易シンセで楽器の音を合成する）。
1曲4〜35KBと、MP3の約1/50の大きさ。ゲーム内の遊び方に「BGM：魔王魂」とクレジットを入れている。

■ 使っている曲（core.js の BGM_LIST と FLOOR_BGM）
  各階のテーマに合わせて、MIDIの中身（テンポ・調・音の密度・打楽器・音域・楽器）から曲の雰囲気を調べて割り当てている。

  戦闘               battle19    とても速く激しい（テンポ280・歪んだギター）ループ 5.44秒 → 39.73秒
  各階の番人         battle18    短調で激しい（各階のボス・スフィンクス・封印の間の守護者）ループ 2.97秒 → 56.30秒
  最後の戦い         battle20    音数が最も多い（灰の司祭モルヴァン戦）曲全体をループ
  地下1階 旧坑道      dangeon03   打楽器ほぼ無し・ギター：落ち着いた歩み（冒険の始まり）
  地下2階 地下水路    dangeon13   柔らかく細かい音：水の流れ
  地下3階 回転床      dangeon09   音がまばらで調がはっきりしない：方向を見失う不思議さ
  地下4階 番兵の詰所  dangeon04   速い・ピチカートと打楽器：見回りの緊張感
  地下5階 蒼き紋の迷宮  dangeon01   高い音域・ハープと合唱：魔法の空間
  地下6階 石像の広間  dangeon05   遅く力強い・金管：重く静まり返った広間
  地下7階 泥濘の底      dangeon02   歪んだギター・低音：まとわりつく重苦しさ
  地下8階 ひび割れた深層    dangeon06   速く音が多い：落下の危険と激しさ
  地下9階 黒曜の回廊    dangeon10   低音が多い・合唱：暗く不穏
  地下10階 封印の間   dangeon23   テンポが揺れる・打楽器無し：聖域の荘厳さ

  ※ループは、曲の中にあるループの印（CC111、RPGツクール式）から曲の終わりまで。
    印の前の部分（イントロ）は最初の1回だけ流れる。
  ※割り当ては FLOOR_BGM の並びで変えられる。

■ このフォルダにあるMP3について
  maou_game_battle21.mp3・dangeon09/10/13.mp3 などは、MIDIに切り替えたので使っていない
  （あそびコレクションにはコピーしない）。フェードアウトを切ったファイルも使っていない。

■ 曲を追加・差し替えるとき
  BGM_LIST に { midi: "ファイル名.mid", vol: 0.42 } を足し、FLOOR_BGM で階に割り当てる。
  ループの印があれば自動でそこからループする（印が無い曲は曲全体を繰り返す）。
  音の大きさが曲によって違う場合は vol で調整する。

■ 曲を追加・差し替えたあとに必ずやること（bgm_data.js の作り直し）
  このフォルダで次のコマンドを実行する：  node make_bgm_data.js
  ・ゲームをファイルのダブルクリック（file://）で開いた時は、ブラウザの制限で .mid を直接読み込めない。
    そのため MIDI のデータを bgm_data.js に埋め込み、それを使って鳴らしている。
  ・作り直さないと、新しい曲がファイルを直接開いた時に鳴らない（サーバー経由・スマホアプリでは .mid から読むので鳴る）。
  ・make_bgm_data.js は、core.js の BGM_LIST に書いてある曲だけを埋め込む（フォルダにあっても使っていない曲は入れない）。

■ 使っていない曲（フォルダにあるが、ゲームでは鳴らしていない）
  battle17・battle21。使う場合は BGM_LIST に追加する。
