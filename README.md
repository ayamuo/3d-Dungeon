# 星灯の迷宮 ― 十層の封印 ―

ブラウザで遊べる、昔ながらの3Dダンジョン探索RPGです。
鉱山町グレイヴンの坑道の底に広がる十層の封印迷宮へ潜り、奪われた〈星灯〉を取り戻します。

**遊ぶ**：https://ayamuo.github.io/3d-Dungeon/

- スマホ・パソコンのブラウザで動きます（インストール不要）
- タップ、キーボード、ゲームコントローラーで操作できます
- 記録はブラウザの中に自動で保存されます（3つまで）
- 遊び方はゲーム内の「？」ボタンから見られます
